이 페이지는 `agent-reach` 패키지의 빌드 설정, 런타임 의존성, 선택적 extras, `console_scripts` 엔트리포인트, 그리고 wheel에 번들되는 비-Python 데이터 디렉터리를 문서화합니다. 내용은 주로 `pyproject.toml`에서 도출되었습니다.

## 빌드 시스템

패키지는 [hatchling](https://hatch.pypa.io/)을 PEP 517 빌드 백엔드로 사용합니다 [pyproject.toml:60-62]().

| 필드 | 값 |
|---|---|
| `build-backend` | `hatchling.build` |
| `requires` | `["hatchling"]` |

wheel 대상은 `agent_reach` Python 패키지로 명시적으로 범위가 지정됩니다 [pyproject.toml:64-65]().

## 패키지 메타데이터

패키지 메타데이터는 프로젝트의 정체성과 지원 환경을 정의합니다 [pyproject.toml:1-28]().

| 필드 | 값 |
|---|---|
| `name` | `agent-reach` |
| `version` | `1.3.0` |
| `requires-python` | `>=3.10` |
| `license` | MIT |
| 지원 Python 버전 | 3.10, 3.11, 3.12, 3.13 |

참고: CI 테스트는 Python 3.10부터 3.13까지를 커버합니다 [.github/workflows/pytest.yml:13]().

## Console Scripts 엔트리포인트

패키지는 하나의 명령행 엔트리포인트를 등록합니다 [pyproject.toml:52-53]().

| 셸 명령 | Python 대상 |
|---|---|
| `agent-reach` | `agent_reach.cli:main` |

`pip install agent-reach`가 완료되면 pip는 `agent_reach/cli.py`의 `main()`을 호출하는 `agent-reach` 실행 파일을 작성합니다. 이것이 지원되는 유일한 CLI 호출 경로입니다 [tests/test_cli.py:13-15]().

## 선택적 Extras

세 개의 명명된 extras가 무거운 선택적 의존성을 제어합니다 [pyproject.toml:40-43]().

| Extra | 설치 명령 | 추가되는 패키지 | 활성화되는 기능 |
|---|---|---|---|
| `[browser]` | `pip install agent-reach[browser]` | `playwright>=1.40` | 헤드리스 브라우저 자동화(예: 복잡한 웹 스크래핑) |
| `[cookies]` | `pip install agent-reach[cookies]` | `browser-cookie3>=0.19` | `agent-reach configure`의 `--from-browser` 자동 추출 |
| `[all]` | `pip install agent-reach[all]` | `playwright`, `mcp[cli]`, `browser-cookie3` | MCP 클라이언트 지원을 포함한 모든 선택적 기능 |

`[all]`의 일부인 `mcp[cli]` 패키지는 채널이 `mcporter`를 통해 로컬 MCP 서버와 상호작용할 때 사용됩니다.

## 번들된 패키지 데이터

Hatchling의 `force-include` 지시문은 비-Python 디렉터리들이 wheel에 포함되도록 보장합니다 [pyproject.toml:67-70]().

| 디렉터리 | 내용 | 소비자 |
|---|---|---|
| `agent_reach/guides/` | Markdown 문제 해결 및 설정 가이드 | CLI 또는 로컬 파일 시스템을 통해 접근 가능 |
| `agent_reach/skill/` | `SKILL.md` — AI 에이전트 스킬 설명자 | `agent-reach install`에 의해 에이전트 디렉터리에 등록됨 |
| `agent_reach/scripts/` | 유틸리티 스크립트(예: `sync-upstream.sh`) | 내부 개발 및 동기화 워크플로 |

```toml
[tool.hatch.build.targets.wheel.force-include]
"agent_reach/guides" = "agent_reach/guides"
"agent_reach/skill" = "agent_reach/skill"
"agent_reach/scripts" = "agent_reach/scripts"
```

## 의존성 잠금

개발과 CI에서는 Agent Reach가 `constraints.txt`를 사용해 재현 가능한 의존성 기준선을 보장합니다 [docs/dependency-locking.md:1-4]().

**안정된 환경 설정:**
```bash
pip install -c constraints.txt -e .[dev]
```

이것은 현재 테스트 스위트에서 검증된 특정 버전들(예: `requests==2.32.5`, `yt-dlp==2025.5.22`)을 고정합니다 [constraints.txt:5-11]().

출처: [docs/dependency-locking.md:13-15](), [constraints.txt:1-18]()
