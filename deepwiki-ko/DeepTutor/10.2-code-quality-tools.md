## 개요

DeepTutor는 저장소 루트에 구성된 자동화 도구 모음을 통해 코드 품질과 보안에 대한 높은 기준을 유지합니다. 이러한 도구는 Python backend와 Next.js frontend 전반의 일관성을 보장합니다 [.pre-commit-config.yaml:1-107]().

- **Ruff**: 고성능 Python linting 및 formatting [.pre-commit-config.yaml:42-51]().
- **Prettier**: frontend 자산과 설정 파일에 대한 일관된 formatting [.pre-commit-config.yaml:55-62]().
- **detect-secrets**: 높은 엔트로피 문자열과 하드코딩된 secret을 검사 [.pre-commit-config.yaml:66-72]().
- **Bandit**: Python 코드에서 흔한 보안 취약점을 분석 [.pre-commit-config.yaml:84-91]().
- **MyPy**: 코드 신뢰성을 보장하기 위한 정적 타입 검사 [.pre-commit-config.yaml:97-106]().
- **Safety/Bandit**: dependency와 코드에 대한 보안 분석 [pyproject.toml:163-164]().

**Sources:** [.pre-commit-config.yaml:1-107](), [pyproject.toml:157-180]()

## Pre-commit 인프라

### 설치와 설정

DeepTutor는 모든 `git commit` 전에 자동으로 검사를 실행하기 위해 `pre-commit` 프레임워크를 사용합니다. 개발자는 이를 로컬에서 초기화해야 합니다 [.pre-commit-config.yaml:4-10]().

```bash
# Install pre-commit
pip install pre-commit

# Install Git hooks
pre-commit install

# Run on all files manually before PR
pre-commit run --all-files
```

**Sources:** [.pre-commit-config.yaml:1-11]()

## Python 코드 품질

### Ruff (Linter & Formatter)

DeepTutor는 통합 Python toolchain을 위해 Ruff를 사용합니다. 개발 중 마찰을 최소화하기 위해 특정 인자로 실행되도록 구성되어 있습니다.

| Hook ID | Arguments | Purpose |
|---------|-----------|---------|
| `ruff` | `--fix`, `--quiet`, `--exit-zero` | 코드를 lint하고 import/style에 대한 자동 수정을 적용 [.pre-commit-config.yaml:45-47](). |
| `ruff-format` | `--quiet` | 일관된 코드 들여쓰기와 따옴표 사용을 보장 [.pre-commit-config.yaml:49-51](). |

**Sources:** [.pre-commit-config.yaml:42-51]()

### Type Checking (Mypy)

DeepTutor는 정적 타입 분석을 위해 Mypy를 사용합니다. 현재는 코드베이스 전반에 점진적으로 도입할 수 있도록 검사가 완화되어 있습니다 [.pre-commit-config.yaml:95-98]().

- **Exclusions**: `deeptutor/agents/`, `deeptutor/services/rag/`, `deeptutor/api/routers/` 같은 특정 디렉터리는 legacy 노이즈를 피하기 위해 현재 엄격한 검사에서 제외됩니다 [.pre-commit-config.yaml:102]().
- **Dependencies**: `PyYAML`, `requests`, `croniter`에 대한 type stub을 포함합니다 [.pre-commit-config.yaml:104-106]().

**Sources:** [.pre-commit-config.yaml:97-107]()

## 프런트엔드 및 Web 품질

### Prettier

Prettier는 `web/` 디렉터리의 formatting을 담당하며, TypeScript, CSS, Markdown을 다룹니다 [.pre-commit-config.yaml:55-62]().

- **Target Files**: `web/**/*.{css,scss,json,jsonc,yaml,yml,md,graphql,html,ts,tsx,js,jsx}` [.pre-commit-config.yaml:60]().
- **Exclusions**: `node_modules`, `.next`, `out`, `dist`, `build` [.pre-commit-config.yaml:61]().

**Sources:** [.pre-commit-config.yaml:55-62]()

## 보안 스캔

### detect-secrets

자격 증명 유출을 방지하기 위해 `detect-secrets`는 baseline 파일을 기준으로 코드베이스를 검사합니다 [.pre-commit-config.yaml:66-72]().

- **Baseline**: `.secrets.baseline`은 알려진 false positive와 허용된 고엔트로피 문자열을 추적하는 데 사용됩니다 [.pre-commit-config.yaml:70]().
- **Exclusions**: `package-lock.json`은 secret 탐지에서 제외됩니다 [.pre-commit-config.yaml:71]().

**Sources:** [.pre-commit-config.yaml:66-72]()

### Bandit

Bandit은 `subprocess` 또는 `yaml.load`의 안전하지 않은 사용과 같은 Python 코드의 일반적인 보안 문제를 찾기 위해 보안 지향 정적 분석을 수행합니다 [.pre-commit-config.yaml:84-91]().

- **Configuration**: 규칙 설정에는 `pyproject.toml`을 사용합니다 [.pre-commit-config.yaml:88]().
- **Exclusions**: `tests/` 디렉터리는 보안 lint에서 제외됩니다 [.pre-commit-config.yaml:89]().

**Sources:** [.pre-commit-config.yaml:84-91]()

## 통합 및 테스트

DeepTutor는 단위 및 통합 테스트에 `pytest`를 사용합니다. 테스트 인프라는 `PromptManager` [tests/core/test_prompt_manager.py:11-152]()와 RAG pipeline [tests/services/rag/test_rag_pipelines.py:1-166]() 같은 핵심 서비스를 다룹니다.

### RAG 통합 테스트
`tests/services/rag/test_pipeline_integration.py`의 `PipelineIntegrationTest` 클래스는 RAG knowledge base의 전체 수명 주기를 검증합니다 [tests/services/rag/test_pipeline_integration.py:68-84]():

1. **Setup**: 테스트를 위한 임시 디렉터리를 생성하고 `RAGService`를 초기화합니다 [tests/services/rag/test_pipeline_integration.py:85-102]().
2. **Initialization**: `testfile.txt`를 사용해 KB 디렉터리 생성과 파일 인덱싱을 검증합니다 [tests/services/rag/test_pipeline_integration.py:109-132]().
3. **Search**: 알려진 텍스트("Shandong province has a pancake")에 대해 retrieval 정확성을 테스트합니다 [tests/services/rag/test_pipeline_integration.py:144-197](), [tests/services/rag/testfile.txt:1-3]().
4. **Tool Verification**: `rag_tool.py`가 `RAGService`와 올바르게 연동되는지 확인합니다 [tests/services/rag/test_pipeline_integration.py:199-221]().

### Prompt 관리 테스트
`TestPromptManager` 클래스는 시스템의 prompt 로딩과 캐싱 로직의 신뢰성을 보장합니다 [tests/core/test_prompt_manager.py:11-12]():

- **Singleton Pattern**: `PromptManager`가 단일 인스턴스를 유지하는지 확인합니다 [tests/core/test_prompt_manager.py:19-23]().
- **Caching**: 성능 향상을 위해 첫 로드 후 prompt가 캐시되는지 검증합니다 [tests/core/test_prompt_manager.py:71-81]().
- **Language Fallback**: 특정 언어 prompt가 없을 때 시스템이 우아하게 fallback하는지 보장합니다 [tests/core/test_prompt_manager.py:135-142]().
