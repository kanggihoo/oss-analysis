DeepTutor는 다국어 인터페이스와 AI 기반 콘텐츠 생성을 지원하도록 설계된 견고한 국제화(i18n) 프레임워크를 제공합니다. 이 시스템은 프런트엔드에 `i18next`를 활용하고, 번역 관리를 위해 구조화된 locale 디렉터리를 유지합니다. 지원되는 언어 전반에서 정합성을 보장하기 위해, 코드베이스에는 자동 감사 pipeline과 하드코딩 UI 텍스트를 방지하는 lint 규칙이 포함되어 있습니다.

## i18n 통합과 데이터 흐름

프런트엔드는 `i18next` [web/package.json:30]()와 `react-i18next` [web/package.json:38]()를 사용해 동적 번역 기능을 제공합니다. 이 통합 덕분에 사용자가 사이드바나 settings를 통해 언어를 전환하면 component가 반응적으로 업데이트됩니다.

## Locale 파일 구조

DeepTutor는 영어(`en`)와 중국어(`zh`)를 주요 지원 언어로 유지합니다. locale 파일은 `web/locales/` 디렉터리에 위치합니다. 각 파일은 키가 코드에서 사용하는 식별자를 나타내고 값이 지역화 문자열인 JSON 구조를 따릅니다.

### 핵심 네임스페이스: `app.json`

`app.json` 파일은 애플리케이션 UI의 기본 네임스페이스로, 내비게이션, 설정, 모듈별 레이블을 포함합니다.

## 프런트엔드 구현

React component에서는 `react-i18next`의 `useTranslation` hook을 통해 번역에 접근합니다 [web/components/sidebar/SidebarShell.tsx:25](). `SidebarShell.tsx` component는 내비게이션 레이블과 tooltip을 렌더링하는 이 패턴을 보여줍니다.

### 구현 패턴

1.  **Hook Usage**: component는 `const { t } = useTranslation()`을 호출해 번역 함수를 사용합니다 [web/components/sidebar/SidebarShell.tsx:117]().
2.  **Key Reference**: UI 텍스트는 `t('Key Name')`으로 대체됩니다. 예를 들어, sidebar 내비게이션은 `t(item.label)`을 사용해 지역화된 메뉴 항목을 렌더링합니다 [web/components/sidebar/SidebarShell.tsx:190]().
3.  **Tooltips**: `Tooltip` component는 i18n key와 함께 사용되어 sidebar icon에 대한 지역화된 설명을 제공합니다 [web/components/sidebar/SidebarShell.tsx:188-193]().

### 동적 언어 전환
Mastery Path dashboard 같은 특화된 페이지에서는 component가 `i18n.language`를 통해 수동 언어 확인을 수행하여 이중 언어 콘텐츠나 fallback 로직을 처리할 수 있습니다 [web/app/(workspace)/learning/page.tsx:38-40]().

## 테마와 전역 스타일 통합

i18n 시스템은 테마 시스템과도 통합되어 있습니다. 설정 인터페이스가 완전히 지역화되도록 테마 레이블이 locale 파일에 정의되어 있습니다.

- **Theme Labels**: "Snow", "Light", "Cream", "Dark", "Glass"가 지역화됩니다 [web/locales/en/app.json:153-157]().
- **CSS Variables**: `--background`나 `--primary` 같은 변수 값은 `globals.css`에 정의되어 있지만 [web/app/globals.css:24-123](), settings 인터페이스에서 이 테마들의 설명 레이블은 `t()`를 통해 가져옵니다.

## i18n 감사 및 유지보수 pipeline

번역 정합성과 코드 품질을 유지하기 위해 DeepTutor는 `package.json` scripts [web/package.json:14-17]()에 정의된 multi-stage audit pipeline을 구현합니다.

### 감사 스크립트
- `i18n:parity`: `en/app.json`과 `zh/app.json` 간 key 동기화를 확인합니다 [web/package.json:14]().
- `i18n:audit`: `scripts/i18n_audit.mjs`를 사용해 코드베이스에서 누락된 번역이나 사용되지 않는 key를 검사합니다 [web/package.json:15]().
- `i18n:check`: parity 검사와 audit 검사를 함께 실행하는 결합 명령입니다 [web/package.json:17]().

### Lint 규칙
프로젝트는 `i18n-plugin.mjs`를 포함하는 커스텀 ESLint 설정 `eslint.config.mjs`를 사용합니다 [web/eslint.config.mjs:2-9](). `i18n/no-literal-ui-text` 규칙은 `app/`와 `components/` 디렉터리 아래의 UI component에서 하드코딩 문자열 리터럴을 경고 수준으로 표시하도록 설정되어 있습니다 [web/eslint.config.mjs:13]().

### 모듈 번역 범위
다음 모듈은 i18n pipeline에 완전히 통합되어 있습니다:
- **Vision Solver**: 요소, 제약조건, 기하학적 분석 [web/locales/en/app.json:76-103]().
- **Deep Research**: 주제 최적화와 연구 상태 [web/locales/en/app.json:114-122]().
- **Knowledge Base**: 관리, 업로드 상태, 생성 워크플로 [web/locales/en/app.json:127-136]().
- **System Settings**: LLM, Embedding, TTS, Search provider 설정 [web/locales/en/app.json:170-177]().
- **Mastery Path**: 학습 단계, mastery level, 진행 상황 추적 [web/app/(workspace)/learning/page.tsx:127-184]().
