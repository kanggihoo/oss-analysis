# 사실·약속 보호

> 번역·편집·샘플 작성 어디서든 가격·날짜·정책·이름·한정어·약속의 강도와 UI 자리표시자를 바꾸거나 새로 만들지 못하게 하는 지침이다. 공유 계약 S2(보호 항목·하드 페일)를 소유한다.

## 1부. 동작 설명

### 1.1 한눈에 보는 흐름
1. 원문(영어 원문 또는 사용자가 준 한국어)에서 보호 대상 항목을 식별한다.
2. 번역·편집 중 각 항목을 조건째 유지한다. 한정어·부정·예외·확신 수준도 같이 유지한다.
3. 원문에 없는 혜택·긴박감·사과·약속을 추가하지 않고, 통화·시간대·단위를 바꾸지 않는다.
4. 없는 정보가 필요하면 그럴듯한 값을 만들지 않고 중립 자리표시자를 쓴다. 샘플·대안에도 같은 제한이 적용된다.
5. UI 문자열이면 자리표시자·키·마크업을 그대로 두고, 버튼은 실제 동작을, 문구는 실제 결과를 말하게 한다.
6. 마지막 검토 단계에서 원문과 대조한다([edit-and-stop-rule](./edit-and-stop-rule.md) R-10).

### 1.2 범위·통합 지점
- 제공: 보호 항목 목록, 추가·변환 금지 목록, 자리표시자 규칙, UI 문자열 규칙.
- 제외: 충돌하는 두 버전 중 무엇을 따를지([input-mode-and-authority](./input-mode-and-authority.md)), 채점 시 하드 페일 판정의 점수 처리([evaluation-rubric](./evaluation-rubric.md)).
- 외부 의존·선행 계약: 없음.
- 소유 상태·부작용: 없음.
