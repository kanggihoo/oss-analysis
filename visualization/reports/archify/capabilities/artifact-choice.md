# 산출물 선택

> 사용자 요청과 컨텍스트의 규칙 줄 `[archify explainer: proactive|always-on|on-demand]`을 받아, native 다이어그램 / explainer 페이지 / 텍스트 답 중 무엇을 만들지 정하고, 모드 제안과 규칙 줄 기록을 처리하는 지시문 묶음.

## 1부. 동작 설명

### 1.1 한눈에 보는 흐름 [필수]
이 기능은 코드가 아니라 `SKILL.md`의 지시문이다. 코드는 선택에 관여하지 않는다(R-16). 호스트 에이전트가 스킬 description을 보고 스킬을 불러온 뒤 아래 순서로 판단한다.
1. 요청이 시스템·흐름·스키마·이력을 그려 달라는 것이면 native 다이어그램으로 가고 타입은 `type-routing.md`가 정한다(R-02).
2. 요청이 "답을 페이지로" 달라는 것이면 explainer를 만든다(R-03). 둘 다 아니면 텍스트로 답하거나 요청한 다이어그램을 그린다(R-04).
3. 컨텍스트에 규칙 줄이 있으면 2번의 기본값이 바뀐다(R-06~R-08). 모든 모드에서 "결론과 구조가 있는 답"만 페이지 대상이다(R-09).
4. explainer를 만들면 작성·전달은 explainer 경로로 넘긴다(R-10). 사용자가 받은 동결 후보(frozen candidate)는 바로 `finalize`로 보낸다(R-11).
5. 요청으로 explainer를 만들었고 규칙 줄이 없으면 답 끝에 모드 제안 한 줄을 붙인다(R-12). 수락하면 전역 규칙 파일에 `proactive` 줄을 추가하고(R-13), 거절하면 `on-demand` 줄을 제안한다(R-14).

### 1.2 범위·통합 지점 [필수]
- 제공: 세 산출물 중 선택 기준, 규칙 줄 세 모드의 의미, 모드 제안 문장과 규칙 줄 기록 규칙.
- 제외: 타입 선택(`type-routing.md`), native 다이어그램 작성(`authoring-contract.md`), explainer 초안 문법·검증(feature map 행 10), `finalize`(행 4), native 다이어그램 답변 형식(`SKILL.md:124-133`, 새 기능 후보로 보고).
- 외부 의존: 규칙 줄을 컨텍스트에 싣는 호스트(전역 `CLAUDE.md`·`AGENTS.md` 등). 스킬은 파일을 직접 읽지 않는다. 이 줄을 읽는 코드는 레포 전체에 없다(R-16).
- 소유 상태·부작용: 규칙 줄 한 줄을 사용자 승인 뒤 전역 규칙 파일에 추가하는 것이 유일한 영속 상태다(R-13). "대화당 한 번" 제안 여부는 대화 맥락에 있고 저장 상태가 없다.

### 1.3 인터페이스와 데이터 의미 [필수]
| 연산·데이터 | 입력·출력 / 타입 | 의미·제약 |
|---|---|---|
| 요청 | string(사용자 발화) | 페이지 요청 표현 예: 한 페이지, explainer, 공유용, `做成一页`, `用页面讲`, `answer with a page`(`SKILL.md:21`) |
| 규칙 줄 | 컨텍스트의 한 줄. 토큰은 `[archify explainer: proactive]`, `[archify explainer: always-on]`, `[archify explainer: on-demand]` | 원문 그대로 쓰는 외부 계약. 이 줄이 없으면 "규칙 줄 없음" 상태이며 기본 동작은 R-03·R-04 |
| 산출물 | native 다이어그램 / explainer 페이지 / 텍스트 | `always-on`만 한 답에 텍스트와 페이지를 함께 낸다(R-07). `proactive`도 텍스트 답에 페이지를 더한다(R-06) |
| 모드 제안 문장 | string(한 줄) | 예: `需要的话，以后遇到解释、对比、排查这类问题，我可以主动做成这样的页面，要开启吗？`(C-02). 언어는 사용자 언어를 따르는 것으로 `추론` |
| 기록할 규칙 줄 | string | C-02의 문구 그대로. 기록 위치는 현재 에이전트의 전역 규칙 파일(예: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.config/devin/AGENTS.md`)이고 파일 이름을 사용자에게 알린다 |

### 1.4 행동 규칙과 남은 질문 [필수]

| R-09 | 모든 모드 | 결론과 그 뒤의 구조가 있는 답만 페이지를 받는다. 대화, 한 줄 답, 명령 출력 원문, 텍스트만 요청한 경우는 받지 않는다. 이 규칙이 R-06·R-07보다 우선한다 | 코드 확인(지시문). 우선순위 해석은 추론 |
