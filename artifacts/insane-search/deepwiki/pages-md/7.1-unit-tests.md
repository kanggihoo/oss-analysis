This page documents the unit testing suite for the `insane-search` engine. The tests are designed to be deterministic and network-free where possible, ensuring that core logic—such as the diversity scheduler, response validation, and the self-learning store—operates correctly across all supported platforms without relying on live site behavior.

## Overview of Test Suite

The test suite is located in `skills/insane-search/engine/tests/` and follows a naming convention from `test_u1.py` through `test_u7.py`. These tests lock in fixes from multi-AI reviews and prevent regressions in the WAF-bypass logic.

| File | Primary Focus | Key Entities Tested |
| :--- | :--- | :--- |
| `test_u1.py` | Scheduler & Validator v2 | `_build_plan`, `validate`, `Verdict` |
| `test_u4.py` | Transport & Sessions | `SessionPool`, `_parse_envelope` |

## U1: Scheduler Diversity & Validator v2

The `test_u1.py` file ensures the fetch grid maintains high entropy and that the validator correctly classifies complex WAF responses.

### Grid Diversity Implementation
The scheduler must cover all TLS families and URL transforms within a small attempt budget. `t_scheduler_diversity_under_cap` verifies that the first 11 attempts (budget minus probe) include:
* **TLS Families:** `safari`, `safari_ios`, `chrome`, `chrome_android`, `edge`. [skills/insane-search/engine/tests/test_u1.py:58-60]()
* **Transforms:** `original` and `mobile_subdomain`. [skills/insane-search/engine/tests/test_u1.py:59-61]()

### Validator v2 Logic
The validator was updated to handle edge cases where a legitimate page might look like a challenge:
* **Small JSON:** Valid JSON responses (even if small) are marked `Verdict.WEAK_OK` instead of `CHALLENGE`. [skills/insane-search/engine/tests/test_u1.py:90-95]()
* **Akamai _abck:** If a cookie contains `~-1~`, it is unresolved. The validator returns `Verdict.SUSPECT_OK`, which is non-terminal, allowing the grid to continue. [skills/insane-search/engine/tests/test_u1.py:98-103]()
* **Soft Marker Overrides:** If a "soft" keyword like "captcha" appears but a `success_selector` matches, the verdict is upgraded to `Verdict.STRONG_OK`. [skills/insane-search/engine/tests/test_u1.py:106-110]()

**Sources:** [skills/insane-search/engine/tests/test_u1.py:52-62](), [skills/insane-search/engine/validators.py:69-80](), [skills/insane-search/engine/validators.py:120-123]()

## U5: Self-Learning Store (learning.py)

`test_u5.py` validates the persistence and eviction logic of the self-learning store. The store records successful fetch routes (impersonate × referer × transform) to skip rediscovery on subsequent visits to the same host.

### Learning State Machine
The test suite exercises the strike-based eviction policy defined in `learning.py`.

Successful Fetch Path to Learned State
```mermaid
graph TD
    "Start_Fetch" --> "Lookup_Host"
    "Lookup_Host" -- "Not Found" --> "Run_Full_Grid"
    "Lookup_Host" -- "Found" --> "Promote_Route_to_Probe"
    "Run_Full_Grid" -- "Success" --> "record_success()"
    "record_success()" --> "Update_wins_and_reset_strikes"
    "Update_wins_and_reset_strikes" --> "Save_to_learned.json"
    
    "Promote_Route_to_Probe" -- "Real_Failure" --> "record_failure(penalize=True)"
    "record_failure(penalize=True)" --> "Increment_consecutive_fails"
    "Increment_consecutive_fails" -- "Fails >= 2" --> "Evict_Entry"
    "Increment_consecutive_fails" -- "Fails < 2" --> "Keep_Entry"
```

### Key Behaviors Tested
* **LRU Capping:** Verifies that when `MAX_ENTRIES` is exceeded, the least-recently-used entries are pruned. [skills/insane-search/engine/tests/test_u5.py:109-122]()
* **Failure Classification:** Distinguishes between "real" failures (WAF blocks) that earn strikes and "transient" failures (429s, network errors) that do not. [skills/insane-search/engine/tests/test_u5.py:84-89]()
* **Key Scoping:** Ensures `desktop` and `mobile` routes for the same host are stored separately. [skills/insane-search/engine/tests/test_u5.py:126-129]()

**Sources:** [skills/insane-search/engine/learning.py:8-16](), [skills/insane-search/engine/learning.py:32-37](), [skills/insane-search/engine/tests/test_u5.py:67-75]()

## U7: SSRF & Redirect Guards

The `test_u7.py` file covers the safety mechanisms in `engine/safety.py` and `engine/transport.py`. It ensures the tool cannot be used to probe internal infrastructure.

### Safety Verification Grid
The tests verify that `classify_url` blocks the following patterns:
* **Loopback:** `127.0.0.1`, `[::1]`, `localhost`. [skills/insane-search/engine/tests/test_u7.py:20-29]()
* **Cloud Metadata:** `169.254.169.254`. [skills/insane-search/engine/tests/test_u7.py:21-21]()
* **Private Ranges:** `10.0.0.0/8`, `192.168.0.0/16`. [skills/insane-search/engine/tests/test_u7.py:22-24]()
* **Invalid Schemes:** `ftp://`, `file://`. [skills/insane-search/engine/tests/test_u7.py:27-28]()

### Redirect Handling
`SessionPool._fetch_following` is tested to ensure it validates every hop in a redirect chain. If a public URL redirects to an internal IP, the chain is aborted with `ssrf_redirect_blocked`. [skills/insane-search/engine/tests/test_u7.py:64-71]()

**Sources:** [skills/insane-search/engine/tests/test_u7.py:18-34](), [skills/insane-search/engine/tests/test_u7.py:64-72]()

## Smoke & Regression Tests

`test_smoke.py` provides integration-level coverage by hitting benign endpoints (like `example.com`) to verify end-to-end behavior.

### Implementation Details
* **Body Size Heuristics:** `t_validator_tiny_body_is_challenge` verifies that a 200 OK response with a body below `SMALL_BODY_THRESHOLD` (3000 bytes) is flagged as a `CHALLENGE` unless overridden. [skills/insane-search/engine/tests/test_smoke.py:29-38]()
* **URL Transform Permutations:** `t_url_transforms` ensures `iter_transformed` correctly generates `m.` subdomains for both `www` and apex domains. [skills/insane-search/engine/tests/test_smoke.py:82-92]()
* **Trace Integrity:** Ensures every `fetch` result contains a complete `trace` of `Attempt` objects, even on failure. [skills/insane-search/engine/tests/test_smoke.py:112-119]()

**Sources:** [skills/insane-search/engine/validators.py:66-66](), [skills/insane-search/engine/tests/test_smoke.py:29-38](), [skills/insane-search/engine/tests/test_smoke.py:82-92]()
