This page describes how to install `agent-browser`, including npm installation methods, Chromium browser setup, system dependencies, and the platform-specific binary distribution mechanism.

## Overview

The `agent-browser` package consists of two main components:

1.  **Native CLI Binary**: A 100% Rust executable that manages the daemon lifecycle, parses commands, and communicates via CDP [docs/src/app/installation/page.mdx:5-12]().
2.  **Chromium Browser**: A "Chrome for Testing" build managed by the CLI's internal installer [cli/src/install.rs:7-15]().

The CLI binary is automatically downloaded during npm installation via a `postinstall.js` script [scripts/postinstall.js:4-10](). The Chromium browser is installed via the `agent-browser install` command [scripts/postinstall.js:205]().

### Supported Platforms
Native Rust binaries are provided for various architectures and are built using GitHub Actions workflows [ .github/workflows/release.yml:71-117]().

| Platform | Architecture | Binary Name |
| :--- | :--- | :--- |
| Linux (glibc) | x64 | `agent-browser-linux-x64` |
| Linux (glibc) | ARM64 | `agent-browser-linux-arm64` |
| Linux (musl/Alpine) | x64 | `agent-browser-linux-musl-x64` |
| Linux (musl/Alpine) | ARM64 | `agent-browser-linux-musl-arm64` |
| macOS | x64 | `agent-browser-darwin-x64` |
| macOS | ARM64 | `agent-browser-darwin-arm64` |
| Windows | x64 | `agent-browser-win32-x64.exe` |

## Installation Methods

### Global Installation (Recommended)
Global installation allows the native Rust binary to be invoked directly with zero-overhead execution by patching npm shims [scripts/postinstall.js:218-220]().

```bash
npm install -g agent-browser
agent-browser install  # Download Chrome
```

### Local Project Installation
For projects pinning a specific version in `package.json`:

```bash
npm install agent-browser
npx agent-browser install
```

### From Source
Requires Node.js 24+, pnpm, and the Rust toolchain ([rustup.rs](https://rustup.rs)) [docs/src/app/installation/page.mdx:46-58]().

```bash
git clone https://github.com/vercel-labs/agent-browser
cd agent-browser
pnpm install
pnpm build
pnpm build:native  # Compiles cli/Cargo.toml
./bin/agent-browser install
```

Sources: [scripts/postinstall.js:146-148](), [bin/agent-browser.js:82-83](), [docs/src/app/installation/page.mdx:48-58](), [.node-version:1]()

## Binary Distribution via postinstall.js

The `postinstall.js` script handles platform detection and binary retrieval to ensure the user receives a native executable without needing a Rust toolchain.

### Implementation Logic
The script performs the following steps:
1.  **Environment Detection**: Uses `os.platform()` and `os.arch()`. It specifically checks for `musl` libc on Linux to support Alpine via `isMusl()` [scripts/postinstall.js:24-36]().
2.  **Download**: Fetches the binary from GitHub Releases using the version from `package.json` [scripts/postinstall.js:42-50]().
3.  **Permission Management**: Applies `chmodSync(binaryPath, 0o755)` on Unix-like systems to ensure the binary is executable [scripts/postinstall.js:138-140]().
4.  **Install Method Tracking**: Writes a `.install-method` file to the `bin/` directory via `writeInstallMethod()`. This is used by the `upgrade` command to know whether to use `npm`, `pnpm`, `yarn`, or `bun` for updates [scripts/postinstall.js:91-106]().

### Global Optimization
On global installs, the script calls `fixGlobalInstallBin()` to patch npm's bin entries. This bypasses the Node.js wrapper (`bin/agent-browser.js`) and points directly to the native binary [scripts/postinstall.js:7-10]().
*   **Windows**: Overwrites `.cmd` and `.ps1` shims [scripts/postinstall.js:8-9]().
*   **Mac/Linux**: Replaces the symlink to point to the native binary [scripts/postinstall.js:9-10]().

## Chromium Setup

The `agent-browser install` command manages the acquisition of a compatible browser.

### Implementation: install.rs
The CLI does not bundle Chrome. Instead, it downloads "Chrome for Testing" into a local directory: `~/.agent-browser/browsers/` [cli/src/install.rs:10-15]().

1.  **Version Lookup**: Fetches the latest stable version from `LAST_KNOWN_GOOD_URL` [cli/src/install.rs:7-8]().
2.  **Discovery**: The `find_installed_chrome` function scans the directory for binaries matching the platform's naming convention [cli/src/install.rs:17-91]().
3.  **Platform Specifics**: `chrome_binary_in_dir` handles paths for `Google Chrome for Testing.app` (macOS), `chrome` (Linux), and `chrome.exe` (Windows) [cli/src/install.rs:101-152]().

### Linux System Dependencies
On Linux, Chromium requires specific system libraries. The `--with-deps` flag in the `install` command triggers an automated installation of dependencies [scripts/postinstall.js:210](), [docs/src/app/installation/page.mdx:60-66]().

## Updating and Troubleshooting

### Upgrade Command
The `agent-browser upgrade` command automatically detects the installation method (e.g., npm, pnpm, cargo, brew) and executes the correct update command [cli/src/upgrade.rs:142-185](). It checks the npm registry to see if a newer version is available before proceeding [cli/src/upgrade.rs:18-32]().

### Doctor Command
The `agent-browser doctor` command diagnoses installation issues and auto-cleans stale daemon files [docs/src/app/installation/page.mdx:78-82]().

It performs the following checks:
*   **Environment**: CLI version, platform, and disk space [docs/src/app/installation/page.mdx:96]().
*   **Chrome**: Install path, version, and profile count [docs/src/app/installation/page.mdx:97]().
*   **Daemons**: Running sessions and stale `.sock` or `.pid` files [docs/src/app/installation/page.mdx:98]().
*   **Security**: Encryption keys and state file permissions [docs/src/app/installation/page.mdx:100]().
*   **Network**: Reachability of Chrome for Testing CDN and AI Gateway [docs/src/app/installation/page.mdx:102]().

Using the `--fix` flag allows the tool to automatically run `agent-browser install` if Chrome is missing or generate a new encryption key at `~/.agent-browser/.encryption-key` [docs/src/app/installation/page.mdx:111-118]().

Sources: [docs/src/app/installation/page.mdx:78-122](), [cli/src/upgrade.rs:142-221]()
