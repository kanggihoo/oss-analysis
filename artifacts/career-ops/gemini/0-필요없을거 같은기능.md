## AST 관련 

ATS는 보통 **각 회사가 직접 만드는 경우보다 외부 서비스를 사용하는 경우가 훨씬 많습니다.**

구조를 보면:

```text
회사
↓
ATS 서비스 사용
↓
지원자 정보 관리
```

예를 들어 회사가 ATS를 도입하면 지원자는 회사 채용 페이지에서 지원하지만 실제 데이터는 ATS에 저장됩니다.

```text
지원자
↓
채용 페이지
↓
ATS
↓
인사담당자
```

그래서 채용 공고 URL을 보면 종종 ATS 서비스 도메인이 보입니다.

예시:

```text
회사 채용 페이지
↓
greenhouse.io
lever.co
workday.com
ashbyhq.com
```

실제로 해외 기업 채용 공고를 눌러보면:

```text
careers.company.com
↓
Greenhouse

또는

jobs.company.com
↓
Lever
```

로 연결되는 경우가 많습니다.

### 한국은? 
한국도 있습니다. 다만 해외처럼 `greenhouse.io`, `lever.co`가 자주 보이는 구조보다는 조금 더 섞여 있습니다.

한국에서 많이 보이는 형태는 이렇습니다.

```text
1. 사람인 / 잡코리아 / 원티드 / 리멤버 같은 채용 플랫폼
2. 회사 자체 채용 페이지
3. 그리팅 / 나인하이어 / 라운드HR 같은 ATS
4. 대기업 자체 채용 시스템
```

국내 ATS 예시는:

```text
그리팅
나인하이어
라운드HR
잡플렉스
원티드스페이스
```

예를 들어 그리팅은 “채용 관리 솔루션”, 나인하이어는 “올인원 ATS”라고 직접 설명합니다. 지원자 관리, 면접 일정 조율, 채용 홈페이지, 데이터 분석 등을 한곳에서 처리하는 구조입니다.    

한국에서는 보통 이런 식입니다.

```text
지원자 → 사람인/잡코리아/원티드에서 지원
또는
지원자 → 회사 채용 홈페이지에서 지원

그 뒤 내부에서는
→ ATS 또는 자체 시스템으로 지원자 관리
```

대기업은 자체 채용 시스템을 쓰는 경우가 많습니다.

```text
삼성 채용
현대자동차 채용
LG Careers
SK Careers
카카오/네이버 자체 채용 페이지
```

중소기업이나 스타트업은 예전에는 엑셀/이메일로 관리하는 경우도 많았고, 요즘은 그리팅·나인하이어 같은 ATS를 붙이는 경우가 늘어나는 흐름입니다. ATS는 이메일/엑셀 대신 공고 게시, 지원자 스크리닝, 면접 조율, 결과 통보, 인재풀 관리까지 통합 운영하는 소프트웨어입니다.  

정리하면:

```text
한국도 ATS를 쓴다.
다만 모든 회사가 쓰는 건 아니다.
대기업은 자체 시스템 비중이 높다.
스타트업/중견기업은 외부 ATS를 쓰는 경우가 늘고 있다.
채용 플랫폼 지원도 내부적으로 ATS나 유사 시스템과 연결될 수 있다.
```

## LateX 관련 렌더링 

한국에서는 보통 그렇게까지 쓰지 않습니다.
예를 들어 해외 개발자 이력서에서는:

```text
Resume generated with LaTeX
Built PDF using LaTeX
Typeset in LaTeX
```

같은 표현이 종종 보입니다.

하지만 한국 채용에서는:

```text
LaTeX를 빌드하여 만든 PDF
```

자체는 거의 평가 대상이 아닙니다.

채용 담당자가 궁금한 것은:

```text
무엇을 만들었는가
어떤 기술을 사용했는가
어떤 문제를 해결했는가
어떤 성과가 있었는가
```

이지

```text
이력서를 Word로 만들었는가
LaTeX로 만들었는가
```

가 아닙니다.
