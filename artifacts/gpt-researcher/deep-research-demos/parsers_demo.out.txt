== 1. parse_search_queries_response (num_queries=3) ==
[JSON 배열]
  -> [{'query': 'q1', 'researchGoal': 'g1'}, {'query': 'q2', 'researchGoal': 'g2'}]
[코드펜스+앞말]
  -> [{'query': 'q1', 'researchGoal': 'g1'}]
[dict 래퍼 queries]
  -> [{'query': 'a', 'researchGoal': 'b'}]
[dict 래퍼 searchQueries]
  -> [{'query': 'a', 'researchGoal': 'b'}]
[항목 일부 불량(goal 누락/공백/비문자열)]
  -> [{'query': 'ok', 'researchGoal': 'goal'}]
[개수 초과 -> 앞에서 num_queries개]
  -> [{'query': '1', 'researchGoal': 'g'}, {'query': '2', 'researchGoal': 'g'}, {'query': '3', 'researchGoal': 'g'}]
[줄 형식 번호]
  -> [{'query': 'q1', 'researchGoal': 'g1'}, {'query': 'q2', 'researchGoal': 'g2'}]
[줄 형식 불릿+Research Goal]
  -> [{'query': 'q1', 'researchGoal': 'g1'}]
[줄 형식 Goal 없는 마지막 Query는 버림]
  -> [{'query': 'q1', 'researchGoal': 'g1'}]
[줄 형식 Query 앞에 Goal만]
  -> [{'query': 'q1', 'researchGoal': 'g1'}]
[JSON인데 모두 불량 -> 줄 파서로 내려가 []]
  -> []
[빈 문자열]
  -> []
[자연어 문단]
  -> []
[JSON 객체에 배열이 문자열 중간 (정규식 후보 [..])]
  -> [{'query': 'z', 'researchGoal': 'y'}]

== 3. parse_research_results_response (num_learnings=3) ==
[정상 JSON]
  -> {'learnings': ['I1', 'I2'], 'followUpQuestions': ['N1?', 'N2?'], 'citations': {'I1': 'https://a.test'}}
[learning/citation 별칭 키]
  -> {'learnings': ['L1'], 'followUpQuestions': ['Q?'], 'citations': {'L1': 'https://c.test'}}
[learnings가 문자열 리스트]
  -> {'learnings': ['plain1', 'plain2'], 'followUpQuestions': [], 'citations': {}}
[같은 insight 두 번(citation은 나중 것)]
  -> {'learnings': ['dup', 'dup'], 'followUpQuestions': [], 'citations': {'dup': 'https://2'}}
[learnings 4개, 질문 4개 -> 둘 다 3개로 자름]
  -> {'learnings': ['a', 'b', 'c'], 'followUpQuestions': ['1?', '2?', '3?'], 'citations': {}}
[JSON 정상이지만 둘 다 비어 있음 -> 줄 파서로 -> 빈 결과]
  -> {'learnings': [], 'followUpQuestions': [], 'citations': {}}
[줄 형식 Learning [url]:]
  -> {'learnings': ['Insight 1', 'Insight 2'], 'followUpQuestions': ['What next?'], 'citations': {'Insight 1': 'https://a.test', 'Insight 2': 'https://b.test'}}
[줄 형식 본문 속 URL 추출]
  -> {'learnings': ['stuff happened at'], 'followUpQuestions': [], 'citations': {'stuff happened at': 'https://example.com/api/v1?key=value'}}
[줄 형식 URL 뒤에 따옴표 있으면 URL에서 제외]
  -> {'learnings': ['see "" ok'], 'followUpQuestions': [], 'citations': {'see "" ok': 'https://x.test/a'}}
[빈 문자열]
  -> {'learnings': [], 'followUpQuestions': [], 'citations': {}}
