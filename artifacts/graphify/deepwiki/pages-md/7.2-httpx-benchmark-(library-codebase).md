The `httpx` benchmark uses a synthetic 6-file Python codebase modeled after the real-world `httpx` library architecture [worked/httpx/README.md:3-4](). This corpus is designed to test `graphify`'s ability to map a realistic library with clean layering: moving from low-level exceptions and models up through transport and authentication to the high-level client [worked/httpx/README.md:4-5]().

## Corpus Composition
The benchmark consists of 6 core files located in the `worked/httpx/raw/` directory [worked/httpx/README.md:8-11](). The codebase follows a strict functional separation [worked/httpx/review.md:76-85]():

| File | Role | Key Entities |
| :--- | :--- | :--- |
| `exceptions.py` | Error hierarchy | `HTTPError`, `RequestError`, `HTTPStatusError`, `ConnectError` |
| `models.py` | Data structures | `URL`, `Headers`, `Cookies`, `Request`, `Response` |
| `auth.py` | Authentication | `DigestAuth`, `BasicAuth`, `BearerAuth`, `NetRCAuth`, `Auth` |
| `utils.py` | Helpers | `build_url_with_params`, `flatten_queryparams`, `parse_content_type` |
| `transport.py` | Network layer | `HTTPTransport`, `ConnectionPool`, `ProxyTransport`, `MockTransport` |
| `client.py` | Main Interface | `Client`, `AsyncClient`, `BaseClient`, `Timeout`, `Limits` |

**Sources:** [worked/httpx/README.md:8-15](), [worked/httpx/review.md:76-85]()

## Surprising Connections
`graphify` identifies non-obvious dependencies that bridge disparate communities, highlighting architectural "leaks" or complex interdependencies.

*   **DigestAuth ↔ Response:** Unlike standard auth flows, `DigestAuth` must read from a `Response` to parse `WWW-Authenticate` headers for the challenge-response handshake [worked/httpx/README.md:38](). This creates a link between the Auth and Models communities [worked/httpx/review.md:45-46]().
*   **Timeout ↔ Model Dependencies:** The `Timeout` class in `client.py` is inferred to have relationships with `URL`, `Headers`, and `Cookies` in `models.py`, likely due to timeout logic being applied during model instantiation or validation [worked/httpx/GRAPH_REPORT.md:25-30]().
*   **High Betweenness Bridges:** `Response` and `Client` act as high-betweenness centrality bridges (0.168 and 0.177 respectively), connecting the Models community to Transport and Client communities [worked/httpx/GRAPH_REPORT.md:65-70]().

## Benchmark Execution
To reproduce these results, the `graphify` CLI is run against the raw source files. The structural value on a small corpus is for rapid architectural onboarding rather than token savings [worked/httpx/README.md:41]().

```bash
# Install and register skill
pip install graphifyy && graphify install

# Run extraction and analysis on the httpx raw corpus
graphify ./worked/httpx/raw
```
[worked/httpx/README.md:22-32]()
