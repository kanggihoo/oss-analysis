This page documents the results of running `graphify` against the `glitchwerks/rsl-siege-manager` repository at commit `6085fd66`. This corpus represents a real-world, full-stack monorepo containing a Python (FastAPI) backend, a TypeScript (React/Vite) frontend, and a Python Discord bot.

The study explores how `graphify` handles mixed-language environments, large test suites, and database migration documentation.

## Corpus Overview

The `rsl-siege-manager` codebase is structurally complex, making it an ideal candidate for evaluating cross-language inference and community detection.

| Component | Technology | Location |
| :--- | :--- | :--- |
| **Backend** | Python (FastAPI + SQLAlchemy) | `backend/` |
| **Frontend** | TypeScript (React + Vite + Tailwind) | `frontend/` |
| **Bot** | Python (Discord.py) | `bot/` |
| **Database** | Alembic Migrations | `backend/alembic/` |
| **Tests** | Pytest & Vitest | `backend/tests/`, `frontend/src/**/__tests__/` |

## Key Findings

### 1. Test Factory Dominance
When extraction is run without a `.graphifyignore` file, test fixtures and factories tend to dominate the "God Nodes" (highest degree centrality). In this run, 6 of the top 10 nodes were test-related helpers.

*   **Observation:** `_make_siege()` (124 edges) and `_make_member()` (92 edges) were the most connected entities [worked/rsl-siege-manager/GRAPH_REPORT.md:141-142]().
*   **Cause:** Test factories are designed to be called by nearly every test case in a suite to set up domain objects, naturally accumulating edges [worked/rsl-siege-manager/review.md:31-34]().
*   **Mitigation:** Users seeking domain-only insights should use `.graphifyignore` to exclude test directories [worked/rsl-siege-manager/review.md:35-36]().

### 2. Cross-Language Inference
`graphify` successfully identifies relationships between Python and TypeScript entities using name-based similarity, though these are flagged as `INFERRED`.

*   **API Contracts:** An inferred edge was detected between `PostPriorityResponse` (Python Pydantic schema) and `PostPriorityConfig` (TypeScript type) [worked/rsl-siege-manager/GRAPH_REPORT.md:153-156]().
*   **False Positives:** Identically named types in different languages (e.g., `Member`) may trigger inferred edges that do not represent a runtime dependency but rather a shared domain vocabulary [worked/rsl-siege-manager/review.md:80-91]().

### 3. Documentation & Rationale Nodes
The 17 Alembic migrations in the corpus demonstrate how `graphify` treats docstrings. Each migration file (e.g., `0001_initial_schema.py`) generates a `rationale` node containing the migration's purpose, such as "initial schema" or "add autofill columns" [worked/rsl-siege-manager/graph.json:78-103](). These nodes are linked to the code entities within the same migration, providing semantic context for database changes.

## Reproducing the Run

To reproduce the artifacts provided in this case study:

1.  **Clone the Repo:**
    ```bash
    git clone https://github.com/glitchwerks/rsl-siege-manager
    cd rsl-siege-manager
    git checkout 6085fd66
    ```
2.  **Run Extraction:**
    Ensure no `.graphifyignore` is present to include tests.
    ```bash
    graphify extract .
    ```
3.  **Inspect Artifacts:**
    *   `graphify-out/GRAPH_REPORT.md`: The primary text summary.
    *   `graphify-out/graph.json`: The raw node/edge data.
    *   `graphify-out/graph.html`: Interactive visualization.

Sources: [worked/rsl-siege-manager/README.md:12-61]()

## Interpreting Artifacts

### GRAPH_REPORT.md
The report for this corpus identified **1886 nodes** and **3876 edges** [worked/rsl-siege-manager/GRAPH_REPORT.md:7](). It highlights:
*   **God Nodes:** Lists the most connected functions (dominated by test factories in this run) [worked/rsl-siege-manager/GRAPH_REPORT.md:140-150]().
*   **Surprising Connections:** Lists cross-language and cross-community inferred links [worked/rsl-siege-manager/GRAPH_REPORT.md:152-163]().
*   **Community Summaries:** 141 communities were detected, though cohesion was generally low (avg 0.05 - 0.17), indicating a highly distributed or weakly coupled graph topology [worked/rsl-siege-manager/review.md:93-102]().

### graph.json
The JSON export contains detailed metadata for every node, including `source_location` (line numbers), `community` IDs, and `norm_label` for search [worked/rsl-siege-manager/graph.json:5-30]().
