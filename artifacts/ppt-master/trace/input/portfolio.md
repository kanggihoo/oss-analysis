## 2. 대표 프로젝트: 주문 API 응답 속도 개선 (2025)
- 문제: 피크 시간대 주문 조회 API의 p95 응답 시간이 1.8초
- 원인: N+1 쿼리, 인덱스 누락, 동일 상품 정보 반복 조회
- 조치: `selectinload`로 쿼리 수 감소, 복합 인덱스 추가, Redis 상품 cache 도입
- 결과: p95 1.8초 → 0.4초, DB CPU 사용률 70% → 35%
- 내 역할: 원인 분석, 쿼리·인덱스 수정, cache 설계 (3인 팀 중 담당)

## 3. 대표 프로젝트: 배포 파이프라인 자동화 (2024)
- 문제: 수동 배포에 40분 소요, 배포 실패 시 원복 절차가 문서에만 존재
- 조치: GitHub Actions로 test → build → deploy 구성, blue/green 전환, 실패 시 자동 rollback
- 결과: 배포 시간 40분 → 8분, 월 평균 배포 횟수 4회 → 22회
- 내 역할: 파이프라인 설계와 구현 (단독)
