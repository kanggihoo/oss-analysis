This document describes the **Image_Generator** AI role within the PPT Master system. The Image_Generator is a **conditional** role that activates only when AI-generated images are selected during the Strategist's "Eight Confirmations" process. It operates as a **serial blocker** in the pipeline: the Executor roles cannot proceed until image generation is complete and resources are collected in the project directory.

For information about the overall AI role pipeline, see [AI Role System](4.-AI-Role-System). For details on the underlying generation tools, see [Image Generation Tools](5.6.-Image-Generation-Tools).

---

## Role Activation and Position in Pipeline

The Image_Generator role is unique because it is **not always executed**. Its activation depends on a specific user choice during the Strategist's initial confirmation process.

### Serial Blocking Behavior

The Image_Generator creates a **mandatory checkpoint** in the pipeline. The system enforces this through workflow documentation and project structure:

| Pipeline Stage | Status | Blocker Condition |
|---|---|---|
| Strategist | Complete | `spec_lock.md` and `design_spec.md` generated |
| **Image_Generator** | **Blocking** | All images must exist in `projects/<name>/images/` |
| Executor roles | Waiting | Cannot start until `image_prompts.json` and images are available |
| Post-processing | Waiting | Depends on Executor SVG output |

## Input Specification

### Primary Input: Image Resource Manifest

The Image_Generator receives the design specification created by the Strategist. The critical section is the **图片资源清单** (Image Resource Manifest), which uses a status-based tracking system to determine the generator's path.

| Status | Meaning | Image_Generator Action |
|--------|---------|------------------------|
| **Pending** (待生成) | Needs AI generation | Generate optimized prompt → Run `image_gen.py` |
| **Existing** (已有) | User provided | Skip generation, verify file exists in `images/` |
| **Placeholder** (占位符) | To be added later | Skip generation, Executor renders placeholder box |

**Sources:** [skills/ppt-master/references/roles/Image_Generator.md:23-33](), [scripts/docs/svg-image-embedding.md:24-29]()

## Prompt Optimization Strategy

### Unified Prompt Structure

The Image_Generator uses a **Unified Prompt Structure** to ensure consistency across multiple images in a deck. This structure includes:

1.  **Style & Technique**: Technical blueprint, flat design, or 3D isometric.
2.  **Color Constraints**: Explicit HEX codes from `design_spec.md` (e.g., `#1A365D`).
3.  **Compositional Rules**: "Calm left third reserved for title overlay" or "Full-bleed background".
4.  **Negative Prompts**: "NO text, letters, numbers, signs, watermarks".

**Sources:** [examples/ppt169_attention_is_all_you_need/images/image_prompts.json:19-21](), [skills/ppt-master/references/roles/Image_Generator.md:54-67]()

## Catalogs and Templates

The Image_Generator utilizes specific catalogs to maintain visual variety and structural logic:

*   **Image-Type-Templates**: A catalog defining visual structures such as flowcharts, timelines, matrices, and hero backgrounds.
*   **Image-Layout-Patterns**: Rules for how images should be positioned (e.g., bleed, inset, anchor) relative to text content.

## Output Specification

### Mandatory Output: `image_prompts.json` and `.md`

The Image_Generator **must** create the manifest file `projects/<name>/images/image_prompts.json`. This JSON file is the machine-readable input for the batch generation tool.

```json
{
  "project": "attention_is_all_you_need",
  "generated_at": "2026-05-24",
  "deck_rendering": "blueprint",
  "deck_palette": "cool-corporate",
  "color_scheme": {
    "primary": "#1A365D",
    "secondary": "#F5F7FA",
    "accent": "#3182CE"
  },
  "items": [
    {
      "filename": "cover_bg.png",
      "purpose": "Cover background (Slide 01) — hero atmospheric blueprint...",
```

### Image Generation Execution

The role utilizes the `image_gen.py` script, which can operate in manifest mode for batch processing.

```bash
# In-pipeline AI image generation — manifest mode:
python3 skills/ppt-master/scripts/image_gen.py --manifest <project_path>/images/image_prompts.json

# Render human-readable prompt list:
python3 skills/ppt-master/scripts/image_gen.py --render-md <project_path>/images/image_prompts.json
```

## Task Completion Criteria

The Image_Generator role is considered complete only when the following checklist is satisfied:

1.  **Manifest Created**: `image_prompts.json` exists in the `images/` folder.
2.  **Files Present**: Actual image files (PNG/JPG) are located in `projects/<name>/images/`.
3.  **Analysis Complete**: `analyze_images.py` has been run to verify dimensions and aspect ratios.
4.  **Handoff Signal**: The role explicitly states: "图片生成完成，请调用 Executor 角色开始生成 SVG。"
