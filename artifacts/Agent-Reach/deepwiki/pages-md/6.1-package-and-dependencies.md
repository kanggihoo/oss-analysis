This page documents the `agent-reach` package's build configuration, runtime dependencies, optional extras, the `console_scripts` entrypoint, and the non-Python data directories bundled into the wheel. It is derived primarily from `pyproject.toml`.

For context on how the CLI entrypoint is used at runtime, see [CLI Reference](2). For the `agent_reach/skill/` and `agent_reach/guides/` directories bundled as package data, see [AI Agent Integration](5) and [Development](6).

## Build System

The package uses [hatchling](https://hatch.pypa.io/) as its PEP 517 build backend [pyproject.toml:60-62]().

| Field | Value |
|---|---|
| `build-backend` | `hatchling.build` |
| `requires` | `["hatchling"]` |

The wheel target is explicitly scoped to the `agent_reach` Python package [pyproject.toml:64-65]().

## Console Scripts Entrypoint

The package registers one command-line entrypoint [pyproject.toml:52-53]().

| Shell command | Python target |
|---|---|
| `agent-reach` | `agent_reach.cli:main` |

When `pip install agent-reach` completes, pip writes an `agent-reach` executable that calls `main()` in `agent_reach/cli.py`. This is the sole supported CLI invocation path [tests/test_cli.py:13-15]().

## Optional Extras

Three named extras gate optional heavy dependencies [pyproject.toml:40-43]().

| Extra | Install command | Packages added | Enables |
|---|---|---|---|
| `[browser]` | `pip install agent-reach[browser]` | `playwright>=1.40` | Headless browser automation (e.g., for complex web scraping) |
| `[cookies]` | `pip install agent-reach[cookies]` | `browser-cookie3>=0.19` | `--from-browser` auto-extraction in `agent-reach configure` |
| `[all]` | `pip install agent-reach[all]` | `playwright`, `mcp[cli]`, `browser-cookie3` | All optional features including MCP client support |

The `mcp[cli]` package (part of `[all]`) is used when channels interact with local MCP servers via `mcporter`.

## Bundled Package Data

Hatchling's `force-include` directive ensures non-Python directories are embedded in the wheel [pyproject.toml:67-70]().

| Directory | Contents | Consumer |
|---|---|---|
| `agent_reach/guides/` | Markdown troubleshooting and setup guides | Accessible via CLI or local file system |
| `agent_reach/skill/` | `SKILL.md` — AI agent skill descriptor | Registered by `agent-reach install` into agent directories |
| `agent_reach/scripts/` | Utility scripts (e.g., `sync-upstream.sh`) | Internal development and sync workflows |

```toml
[tool.hatch.build.targets.wheel.force-include]
"agent_reach/guides" = "agent_reach/guides"
"agent_reach/skill" = "agent_reach/skill"
"agent_reach/scripts" = "agent_reach/scripts"
```

## Dependency Locking

For development and CI, Agent Reach uses `constraints.txt` to ensure a reproducible dependency baseline [docs/dependency-locking.md:1-4]().

**Stable Environment Setup:**
```bash
pip install -c constraints.txt -e .[dev]
```

This pins specific versions (e.g., `requests==2.32.5`, `yt-dlp==2025.5.22`) that have been validated against the current test suite [constraints.txt:5-11]().

Sources: [docs/dependency-locking.md:13-15](), [constraints.txt:1-18]()
