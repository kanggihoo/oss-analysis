== A. packages: declarationHash는 선언 텍스트의 해시일 뿐 ==

key order 바꿈    07a773da516d (같음이어야 함)
version 1.2.0    bc1103c2905e

base == pinned    : false
(업스트림이 p@m 새 버전을 냈다는 정보는 입력에 없다 -> 해시가 변할 수 없음)
