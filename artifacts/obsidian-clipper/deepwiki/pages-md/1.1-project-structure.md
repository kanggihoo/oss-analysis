## Multi-Browser Manifest System

The extension maintains separate manifest files to accommodate browser-specific differences while sharing the same core codebase. These are unified into a single `manifest.json` during the build process based on the `BROWSER` environment variable [webpack.config.js:142-145]().

### Manifest Variants

| Feature | Chrome | Firefox | Safari |
|---------|--------|---------|--------|
| Manifest file | `src/manifest.chrome.json` | `src/manifest.firefox.json` | `src/manifest.safari.json` |
| Manifest version | 3 | 3 | 3 |
| Background | `service_worker` [src/manifest.chrome.json:39]() | `scripts` array [src/manifest.firefox.json:43]() | `service_worker` |
| Side panel | ✓ (`side_panel`) [src/manifest.chrome.json:26]() | ✗ | ✗ |
| Permissions | `sidePanel`, `declarativeNetRequest` [src/manifest.chrome.json:13-16]() | `webRequest`, `webRequestBlocking` [src/manifest.firefox.json:14-15]() | Standard set |
| Browser ID | N/A | `clipper@obsidian.md` [src/manifest.firefox.json:86]() | Managed by Xcode |

**Sources:** [src/manifest.chrome.json:1-88](), [src/manifest.firefox.json:1-99](), [webpack.config.js:23-38]()

## Source Code Organization

The `src/` directory is organized by architectural role rather than feature alone.

### Core Directory (`src/core/`)
Contains the primary UI logic and orchestration for different extension views.
- `popup.ts`: Manages the clipping interface.
- `settings.ts`: Orchestrates settings initialization, including general, reader, and interpreter settings [src/core/settings.ts:53-58]().
- `highlights.ts`: Logic for the highlights management view.

### Managers Directory (`src/managers/`)
Handles state, storage interaction, and complex business logic for specific domains.
- `template-manager.ts`: Handles loading, saving, and duplicating templates using `browser.storage.sync` [src/managers/template-manager.ts:20-71]().
- `general-settings.ts`: Manages global extension configuration [src/core/settings.ts:13]().
- `interpreter-settings.ts`: Manages AI interpreter configuration and providers [src/core/settings.ts:14]().

### Utils Directory (`src/utils/`)
Stateless helper functions and cross-cutting concerns.
- `i18n.ts`: Internationalization system for translating the UI [src/core/settings.ts:26]().
- `browser-polyfill.ts`: Provides a unified `browser` API across Chrome/Firefox/Safari [src/managers/template-manager.ts:3]().
- `storage-utils.ts`: Low-level storage wrappers.

**Sources:** [src/core/settings.ts:1-26](), [src/managers/template-manager.ts:1-11]()

## Build System and Scripts

The project uses a mix of Webpack for the browser extension and custom scripts for CLI/API distribution.

### Build Scripts Overview

| Command | Action |
|---------|--------|
| `npm run build` | Builds Chrome, Firefox, and Safari production versions [package.json:24]() |
| `npm run build:cli` | Bundles the CLI tool to `dist/cli.cjs` [package.json:25]() |
| `npm run build:api` | Bundles the programmatic API to `dist/api.mjs` [package.json:26]() |
| `npm run update-locales` | Uses AI to translate missing strings in `_locales` [package.json:30]() |
| `./scripts/bump-version.sh` | Updates version in `package.json` and all manifests [scripts/bump-version.sh:21-27]() |

**Sources:** [package.json:15-34](), [webpack.config.js:28-34](), [scripts/bump-version.sh:1-58]()

## Dependencies

### Runtime Dependencies
- **`defuddle`**: The primary engine for extracting content and metadata from HTML [package.json:60]().
- **`lz-string`**: Used to compress templates and settings to stay within browser storage limits [src/managers/template-manager.ts:2](), [package.json:65]().
- **`dompurify`**: Sanitizes content to ensure safe rendering [package.json:61]().
- **`dayjs`**: Used for date manipulation in templates [package.json:59]().

### Development Dependencies
- **`webpack`**: Orchestrates the multi-browser build pipeline [package.json:53]().
- **`ts-loader`**: Compiles TypeScript for the browser [package.json:48]().
- **`sass-loader`**: Compiles SCSS files like `style.scss` and `reader.scss` [webpack.config.js:48-50]().

**Sources:** [package.json:35-66](), [webpack.config.js:103-136]()
