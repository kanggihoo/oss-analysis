The `pi` codebase provides comprehensive utilities for image handling focused on resizing, format conversion, EXIF orientation correction, and clipboard image capture across platforms. These utilities ensure images are correctly processed for terminal display, comply with provider payload limits, and enable seamless cross-platform pasting compatibility.

---

## Image Processing Pipeline

Image processing leverages **Photon** (a Rust-based image processing library compiled to WebAssembly) for core operations. The system implements a robust resizing strategy to ensure images fit within the token and byte limits of LLM providers while maintaining visual fidelity.

### Resizing and Optimization

The main entrypoint `resizeImage` asynchronously resizes images using an intelligent multi-step strategy. It runs Photon in a worker thread to prevent blocking the TUI event loop [packages/coding-agent/src/utils/image-resize.ts:78-84]().

**Key implementation details:**

1.  **Worker Thread Execution**:
    - The `resizeImage` function attempts to spawn a `Worker` using `image-resize-worker.ts` [packages/coding-agent/src/utils/image-resize.ts:91-103]().
    - It uses `toTransferableBytes` to efficiently move data to the worker [packages/coding-agent/src/utils/image-resize.ts:11-15]().
    - If worker initialization fails (common in some Bun-compiled binary layouts), it falls back to `resizeImageInProcess` [packages/coding-agent/src/utils/image-resize.ts:105-109]().

2.  **Constraint Enforcement**:
    - The processor scales images to fit within `maxWidth` and `maxHeight` [packages/coding-agent/src/utils/image-resize.ts:85-89]().
    - If the resulting encoded image exceeds `maxBytes`, the system iteratively reduces quality (for JPEGs) or dimensions until the budget is met.

3.  **Dimension Mapping**:
    - `formatDimensionNote` generates a string explaining the scale factor to the LLM: `[Image: original ...x..., displayed at ...x... Multiply coordinates by ... to map to original image.]` [packages/coding-agent/src/utils/image-resize.ts:116-123]().

### EXIF Orientation Correction

Before resizing or display, images are processed by `applyExifOrientation`. This utility reads TIFF/JPEG/WebP headers to find the orientation tag and applies the necessary flips or rotations using Photon [packages/coding-agent/src/utils/exif-orientation.ts:147-183]().

- **JPEG**: Searches for the `0xffe1` marker and `Exif\0\0` header [packages/coding-agent/src/utils/exif-orientation.ts:39-63]().
- **WebP**: Searches for the `EXIF` chunk within the RIFF container [packages/coding-agent/src/utils/exif-orientation.ts:65-85]().

## Clipboard Image Capture and Management

The clipboard system is designed to work across local and remote (SSH) sessions, supporting Linux (X11/Wayland), macOS, and Windows (including WSL).

### Implementation Strategies

The core function `readClipboardImage` selects a strategy based on the detected environment:

-   **Wayland**: Uses `wl-paste --list-types` to find preferred MIME types and `wl-paste --type ...` to extract data [packages/coding-agent/src/utils/clipboard-image.ts:118-141]().
-   **WSL (Windows Subsystem for Linux)**: Since Linux tools cannot access the Windows clipboard directly, it uses a PowerShell script to invoke `[System.Windows.Forms.Clipboard]::GetImage()` and saves it to a temporary file [packages/coding-agent/src/utils/clipboard-image.ts:161-201]().
-   **X11**: Uses `xclip -selection clipboard -t TARGETS` [packages/coding-agent/src/utils/clipboard-image.ts:213-238]().
-   **Native Addon**: Uses `@mariozechner/clipboard` (a Rust-based native binding) for macOS and Windows [packages/coding-agent/src/utils/clipboard-native.ts:17-32]().

### BMP to PNG Conversion

On Windows/WSL, images are often stored in the clipboard as BMP. The system automatically converts these to PNG using Photon's `get_bytes()` method to ensure cross-platform compatibility and terminal support [packages/coding-agent/src/utils/clipboard-image.ts:71-87]().

### Text Copying and OSC 52

For text, `copyToClipboard` attempts native tools first (`pbcopy`, `clip.exe`, `wl-copy`) [packages/coding-agent/src/utils/clipboard.ts:66-113](). If in a remote session (SSH/Mosh) or if native tools fail, it emits an **OSC 52** escape sequence to the terminal, allowing the local terminal emulator to handle the clipboard write [packages/coding-agent/src/utils/clipboard.ts:119-122]().

## Format Conversion and Terminal Compatibility

### Kitty Graphics Protocol Support
The Kitty terminal protocol requires PNG format. The utility `convertToPng` (in `image-convert.ts`) ensures any non-PNG base64 image data is converted using Photon before being sent to the terminal [packages/coding-agent/src/utils/image-convert.ts:8-41]().

### CLI File Processing
When a user provides an `@file` argument that points to an image, `processFileArguments` handles the loading, resizing, and attachment creation [packages/coding-agent/src/cli/file-processor.ts:24-50]().

- It detects MIME types using `detectSupportedImageMimeTypeFromFile` [packages/coding-agent/src/cli/file-processor.ts:48]().
- It automatically triggers `resizeImage` if `autoResizeImages` is enabled [packages/coding-agent/src/cli/file-processor.ts:57-58]().
- It generates a text reference with the dimension note for the LLM context [packages/coding-agent/src/cli/file-processor.ts:80-84]().
